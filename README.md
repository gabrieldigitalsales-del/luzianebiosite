# Reabilitar Psicologia — V8

Projeto React + Vite pronto para importar na Vercel.

## Executar localmente

```bash
npm install
npm run dev
```

## Publicar na Vercel

1. Envie os arquivos da pasta do projeto para um repositório GitHub, ou importe esta pasta na Vercel.
2. Escolha o framework **Vite** (detectado automaticamente).
3. Confirme os ajustes: Build Command `npm run build` e Output Directory `dist`.
4. Publique. `vercel.json` define o fallback de rotas para `index.html`.
